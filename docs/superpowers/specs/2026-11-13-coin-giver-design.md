# 金幣爺爺：沒錢時出現、答對給金幣、對話後換島

日期：2026-11-13　狀態：使用者已確認方向（出題沿用現有、窮的時候才出現、金額改小），細節為我的建議，待使用者審閱本文件

## 背景與目標

- 金幣只能靠戰鬥與寶箱取得，花光後孩子會買不起藥水、住不起旅館。
- 做一個「安全網」角色：孩子真的沒錢時，他出現在主島上，問一題注音，答對就發金幣；他每跟孩子說完話就換到另一座主島。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 題目 | 沿用現有出題（`learning.ts` 的 `makeQuestion`，跟著孩子學過的符號、家長設定），出 1 題 |
| 出現時機 | 只有「孩子沒錢」時才出現在地圖上 |
| 「沒錢」的定義 | 金幣 < 25（旅館價，比小藥水 15 高；`POOR_COINS` 常數，改一個值即可） |
| 獎勵 | 100 金幣（`GIVER_REWARD` 常數） |
| 換島 | 每次對話結束就換到另一座主島 |

## 行為

- **角色**：金幣爺爺（id `giver`、kind `giver`），站在三座主島（鼓聲港 `dh`、蛙鳴灣 `gh`、雪花鎮 `xh`）碼頭附近的空地。起始村（第 0 關）不放。
- **位置**：存檔欄位 `giverAt`（地圖 id，主島之一）。沒有值（新存檔、舊存檔）時用第一座到過的主島（`visited:dh` 優先，依 dh、gh、xh 順序）。
- **可見條件**：目前地圖 = `giverAt`，且 `coins < POOR_COINS`。孩子有錢時三座島都看不到他。
- **對話流程**：
  1. 第一次見面（旗標 `giverMet`）說一段登場台詞，之後直接說「你的口袋空空的呀～答對這題，爺爺就給你 100 金幣」。
  2. 出 1 題（跟戰鬥同樣的題型：選符號／聽音；沒有音檔就用看符號配對，不用 TTS 冒充）。選項後加「🔊 再聽一次」（聽音題）與「先不要」。
  3. 答錯：輕輕提示「再想想看～」可以再選；沒有處罰、沒有題數限制。
  4. 答對：發 `GIVER_REWARD` 金幣、播音效、存檔、說祝賀台詞。
  5. 結束（答對或選了「先不要」）：說一句再見，爺爺消失（簡單的閃光），`giverAt` 改成**另一座**到過的主島（隨機；沒有別的到過的主島就留在原地）。
- **換島的細節**：換到的島只限「到過的主島」（`visited:<map>`），避免孩子還沒去過的島先出現劇情外的角色。他在那座島上直到孩子又窮了，才會被看到。
- **沒題可出**（學過的符號太少、無法出題）：爺爺說「等你再多認識一些符號，爺爺再來」，不發錢也不換島。

## 資料與程式

- `src/core/giver.ts`（純函式，Vitest 測）：`POOR_COINS`、`GIVER_REWARD`、`isPoor(coins)`、`giverVisible(save, mapId)`、`nextGiverMap(save, rng)`（回傳另一座到過的主島或原地）、`defaultGiverMap(save)`。
- `src/core/save.ts`：新增選用欄位 `giverAt?: string`；舊存檔沒有就算未設定（用預設）。比照 `starsSpent` 補預設值的做法，注意 `loadGame` 的預設值陷阱。
- `src/data/maps.ts`：`ObjKind` 加 `'giver'`；`dh`／`gh`／`xh` 各加一個 `giver` 物件，站在可走格旁、不壓住既有物件與碼頭路徑。**不動第 0 關與 `dc1`／`dc2`。**
- `src/scenes/World.ts`：`visible()` 對 `giver` 套用 `giverVisible`；`useGiver()`（`ui.blocking` 成對，`say([])` 不可為空）；換島後 `refreshObjects()`。
- 美術（`src/gfx`）：`giver`／`giver2`（兩格動畫，戴金色帽子、拿錢袋的老爺爺），沿用 `granny` 的建圖方式與圖樣測試。
- 台詞放進 `src/data/levels.ts` 的 `STORY`（比照 `frogHello` 等）。

## 測試

- 單元測試：`isPoor` 邊界（24 窮、25 不窮）；`giverVisible`（有錢隱藏、不在這張地圖隱藏）；`nextGiverMap` 只選到過的別座主島、只有一座時不動；預設位置；舊存檔缺 `giverAt`。
- 地圖測試：三座主島都有 `giver` 且站在可走格、不在阻擋格、不壓碼頭與抵達格；不改變 `dh`／`gh`／`xh` 既有物件座標。
- 端對端：不新增（出題需要機器人答題，成本高）；`tests/layout.test.ts` 若凍結這些島的物件，要同步更新並說明。
- 手動確認：爺爺外觀、出現位置、100 金幣是否合適、換島節奏。

## 不在範圍

- 起始村與其他地圖；多題連答；每次對話後給的別種獎勵；爺爺跨存檔記憶更多狀態；音效新增（沿用 `levelup`）。

## 風險

- 孩子故意把錢花光來刷錢：每次要花光才再窮，且每次只有 100，淨收益不大；可接受。
- 選「先不要」也會換島，孩子可能一時找不到他：他一定在另一座到過的主島，且只有窮的時候才出現；如果要改成「只有答對才換」只要改 `useGiver` 的一行。
