# 寫字施法：用手指寫出 ㄅ 才能打碎石頭

日期：2026-11-11　狀態：設計已與使用者確認

## 目標

遊戲裡「用爆破拳（ㄅ）打碎裂石」目前是點一下石頭就碎。改成：玩家要先用手指（或滑鼠）在畫面上照筆順寫出 **ㄅ**，寫完才會出招、石頭才碎。讓「學注音」多一個動手寫的步驟，也呼應「招式綁符號」。

## 範圍

- 只做**裂石**（村子的 `rock_a`、村外小徑的 `rock_b`），符號只有 **ㄅ**。
- 其他機關（落葉、風車、鈴鐺、迷霧、島上的機關）這次不動。
- 筆順資料做成可擴充的資料表，之後加其他符號只要補資料。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 判定方式 | 照著虛線描：依序經過關鍵點就算過，寬鬆、不卡關 |
| 寫錯 | 沒有懲罰，那一畫輕輕重來，說「再試一次」 |
| 取消 | 畫面上有「先不要」，回到地圖，石頭還在 |
| 家長設定 | 新增「寫字挑戰」開關，預設開；關掉就跟現在一樣直接打碎 |
| 筆順資料 | 照使用者提供的筆順圖；**ㄅ 是一筆寫完** |

## ㄅ 的筆順（讀自使用者提供的圖，座標為 0～100 的近似值）

一筆：起點（左上）→ 往左下斜寫到轉角 → 水平往右寫到右上角 → 往下彎寫、最後勾向左下。

```
points: (31,14) → (19,40) → (78,31) → (76,50) → (66,72) → (55,86) → (49,87)
```

這些座標是照圖量的近似值；畫面上的虛線與箭頭若不順，只要改這幾個數字。

## 玩法流程

1. 玩家點裂石，且已學會爆破拳 → 開一個「寫 ㄅ」的畫布（彈窗）。
2. 畫布上有淡淡的 ㄅ、依筆順畫的虛線、起點圓點與 1、2 的順序數字、終點箭頭；語音念「照著箭頭，把ㄅ寫出來」。
3. 孩子用手指（或滑鼠）從起點描到終點，畫出的線顯示成橘色。
4. 放開手指時判定：這一畫依序經過所有關鍵點 → 變成綠色；全部畫完 → 播放答對音效，畫布關閉，石頭照現在的方式被爆破拳打碎。
5. 沒經過全部關鍵點（偏太多、方向反了、只寫一半）→ 線清掉、輕輕的錯誤音、提示「再試一次」，不扣任何東西。
6. 按「先不要」→ 畫布關閉，石頭還在，什麼都不發生。
7. 還沒學會爆破拳：維持現在「需要很強的拳頭」的說明，不開畫布。

## 判定規則（純邏輯，可單元測試）

- 把目標筆畫沿線每約 8 單位取一個關鍵點（含起點、終點）。
- 把孩子畫的軌跡補點到每約 2 單位一個（避免手指太快跳過關鍵點）。
- 依序走訪軌跡：每次軌跡點離「下一個關鍵點」在容許距離（預設 14 單位）內，就算經過，換下一個。
- 全部關鍵點都依序經過才算這一畫完成；回傳 0～1 的進度，畫面可用來即時變色。
- 方向反了、走捷徑（轉角被切掉）、只寫一半，都不會達到 1。

## 資料與程式

- `src/data/strokes.ts`：`STROKES: Record<符號, 筆畫[]>`，每筆畫是 0～100 座標點列表。
- `src/core/strokes.ts`：純函式 `sampleStroke`、`densify`、`strokeProgress`、`strokeDone`（不依賴 Phaser／DOM）。
- `src/core/ui.ts`：`openWriteSymbol(symbol): Promise<boolean>`，用彈窗＋ `<canvas>` ＋ Pointer Events（滑鼠與觸控通用），完成回傳 `true`，「先不要」回傳 `false`；`ui.blocking` 要成對。
- `src/data/maps.ts`：`MapObj.write?: string`，兩顆裂石設 `write: 'ㄅ'`。
- `src/core/save.ts`：`Settings.writeChallenge`（預設 `true`），家長設定加開關。
- `src/scenes/World.ts`：裂石互動在「已學會爆破拳」之後、`breakRock` 之前，若物件有 `write` 且設定開啟，先 `await openWriteSymbol(...)`，回傳 `false` 就結束。

## 測試

- 單元測試：完美描、有偏差仍通過、方向反、切轉角、只寫一半、空軌跡、取樣點含起終點；資料驗證每個 `write` 符號都有筆順資料。
- 端對端：機器人預設把「寫字挑戰」關掉（維持現有流程），另外對一顆裂石開啟並用滑鼠依筆順拖曳，確認畫布出現、寫完後石頭碎掉。

## 風險

- 畫布大小與觸控：小螢幕要放得下、`touch-action: none` 避免捲動、用 Pointer Capture 避免手指滑出畫布。
- `ui.blocking`：彈窗所有結束路徑（寫完、先不要、例外）都必須 `closeModal()`。
- 判定太嚴孩子會氣餒、太鬆沒意義：容許距離 14 單位是起始值，上線後依實測調整。
- 筆順座標是近似值，需使用者實際看過畫面確認。

## 不在範圍

其他符號的筆順資料與其他機關的寫字要求、動畫示範筆順的小手指、手寫辨識（自由書寫）。
