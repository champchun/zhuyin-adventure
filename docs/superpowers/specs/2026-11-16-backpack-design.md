# 小背包：地圖上可以用藥水／魔力果

日期：2026-11-16　狀態：使用者已確認方向（地圖上使用藥水／魔力果）

## 目標
地圖右上角新增 🎒，打開「我的背包」，列出道具，並可在地圖上對夥伴使用小藥水、大藥水、魔力果。

## 行為
- 入口：HUD 在 🐾 旁加 🎒；`ui.blocking` 時不能開（沿用現有按鈕規則）。
- 畫面：標題、🪙 金幣、數量 > 0 的道具（圖示、名稱、×數量、說明）。空時顯示「背包空空的，去商店買一些吧」。
- 回復道具（有 `hp` 或 `mp`）可點 → 列出夥伴（縮圖、HP、魔力）→ 選一位使用。這位夥伴用不到（已滿）時按鈕變灰並寫「已經是滿的了」，不消耗。用完存檔、畫面即時更新，可連續使用。
- 小鑰匙只顯示數量，註明「開洞窟的鎖門時會自動用掉」。
- 夥伴畫面頂端的道具數量保留。

## 程式
- `src/core/save.ts`：新增純函式 `canUseItem(id, m)`（有庫存且該夥伴需要才 true），`useItem` 改用它，行為不變。
- `src/core/ui.ts`：`openBackpack()`；`setupHud` 增加 `backpack` handler；`src/main.ts` 接上。
- 不新增旗標、不改存檔、不動端對端。

## 測試
Vitest：`canUseItem` 的各種情況（無庫存、已滿、HP 缺、魔力缺、鑰匙不可用），並確認 `useItem` 行為不變（既有測試）。
