# 第六關（最終關）：舌尖前音（ㄗㄘㄙ）與天空島

日期：2026-11-13　狀態：使用者已確認方向（熱氣球上天、星空龍王前加一個小王把全部聲母教完、星空龍王就是畢業考、結尾劇情加稱號），其餘細節為我的建議，待使用者審閱本文件

## 背景與目標

- 前五關教完 18 個聲母（ㄅㄆㄇㄈ、ㄉㄊㄋㄌ、ㄍㄎㄏ、ㄐㄑㄒ、ㄓㄔㄕㄖ）。最後一組是舌尖前音 ㄗ ㄘ ㄙ，這是最終關。
- 沿用前幾關的做法：一座主島 + 一座怪物島（含兩層洞窟）、旅館、商店、第一次認識符號的小課程、寫字施法、回音怪與頭目護盾。
- **和前幾關不同**：
  1. 從**起始村**出發，搭**熱氣球**上天（要先打倒第五關頭目、學會 ㄖ）。
  2. 最終頭目星空龍王就是**畢業考**：題目從全部 21 個聲母出。
  3. 打完有**結尾劇情**與一個新稱號。

## 範圍

- 主島「雲上小鎮」（`sh`，室內 `sh_inn`、`sh_shop`）、怪物島「星空島」（`s`）、洞窟「星塔」（`sc1`、`sc2`，用迷宮產生器）。
- 起始村新增熱氣球（機關＋可搭乘物件）；天空島的停機坪與回程氣球；主島到怪物島的「雲朵小船」。
- ㄗㄘㄙ 的教學流程、三個新招式與機關、小王與最終頭目、新敵人與圖樣、商店上架、劇情與島民暗示。
- 最終頭目的畢業考、結尾劇情、稱號獎勵、星星婆婆與金幣爺爺在雲上小鎮的位置。
- ㄗㄘㄙ 的寫字筆順資料。
- **不做**：韻母／拼音、第七關、怪物島 B、結尾之後的新內容。

## 熱氣球

- 起始村新增：
  - `balloon_empty`（`gimmick`，貼圖：沒氣的氣球，`ability: 'sun'`，`showIf: 'boss_z'`）：對它施放 ㄖ（寫字施法），氣球鼓起來。
  - `balloon`（上天的入口，`showIf: 'g:village:balloon_empty'`）：點它出現「出發」選擇視窗（沿用碼頭的流程），通到雲上小鎮的停機坪。
  - `balloon_sign`（`sign`，`showIf: 'boss_z'`）：說明這顆氣球是做什麼的。
- 雲上小鎮停機坪旁有回程的 `balloon_back`，一個氣球只通一個地方，抵達格旁要有回程。
- 實作上沿用碼頭的程式，但要跳過「靠水」檢查：`hub.test.ts` 會檢查碼頭抵達位置靠水，要用一個欄位（例如 `vehicle: 'balloon' | 'cloudboat'`）標記非船的交通工具，測試依此例外。

## 學習流程與招式

| 注音 | 怎麼學到 | 招式（id／名稱） | 機關 |
|---|---|---|---|
| ㄗ ㄘ | 進島先打稻草布偶（教學戰：第 1 回合看符號、第 2 回合聽聲音）。`LEARN_STEPS`：`['ㄗ','ㄘ']`，旗標 `sEntered` | `zip` 拉鍊（ㄗ）、`spike` 刺球（ㄘ） | ㄗ：拉開雲幕的拉鍊，露出寶箱；ㄘ：刺破擋路的雲團 |
| ㄙ | 小怪考 ㄙ；打倒星空島上、星塔入口前的小王「星門守衛」（`boss_s1`）後學會。`LEARN_STEPS`：`['ㄙ']`，旗標 `sPractice`（由小王戰的獎勵設定，比照第五關的 `zPractice`） | `whistle` 口哨風（ㄙ） | 吹出彩虹橋過缺口，通往對岸的寶箱（小王後才能用）；星塔二樓的開關也用它 |

- 威力：ㄗ 8、ㄘ 8、ㄙ 9（比第五關再高一級；ㄙ 為本關最後學、略強）。
- 招式資料比照現有招式：`MoveDef`、能力旗標、`gimmick` 的 `ability`。能力 id 與招式 id 相同。
- 洞窟內機關：`sc2` 二樓的開關用 `whistle`（ㄙ）。星塔要小王打倒後才開（`cave` 的 `showIf: 'boss_s1'`），所以進塔時 ㄙ 已經學到，**到最終頭目之前全部招式都已到手**。仍要用測試守門：頭目 `boss_s` 的獎勵（沒有新能力）不得是通往它所需的能力，且「通往 `boss_s` 之路」所需能力都必須在 `boss_s1` 之前或獎勵中取得（第五關曾因洞窟機關用了頭目後才學的招式而死結）。

## 場景與地圖

### 主島「雲上小鎮」（`sh`，室內 `sh_inn`、`sh_shop`）

- 沿用其他主島：島民、旅館（25 金幣）、商店、星星婆婆、金幣爺爺（`GIVER_HUBS` 加 `'sh'`）、停機坪（`balloon_back`）、雲朵小船碼頭（去星空島）。
- 地形：雲地、霧氣、星光水池（不可走）、雲屋（沿用四種房子外觀換色）、星形裝飾；格局要和前五個主島不同。
- 被打倒會送回雲上小鎮（`homeMap`，`visited:sh`）。

### 怪物島「星空島」（`s`）

- 進島：稻草布偶（教 ㄗ ㄘ），之後是小怪、機關（拉鍊 ㄗ、雲團 ㄘ 各一個寶箱；彩虹橋 ㄙ 在小王之後才用）、告示牌、回雲上小鎮的雲朵小船。
- **小王「星門守衛」**（`boss_s1`，物件 id `guard`，護盾戰）站在通往星塔入口的路上；打倒後學到 ㄙ，星塔入口 `cave` 才出現（`showIf: 'boss_s1'`）。到這裡全部聲母都教完了。

### 星塔（`sc1`、`sc2`，產生器）

- 兩層，固定種子 67、71（避開 11、23、37、41、53、59），31×22。樓梯、鑰匙、鎖門、隱藏房間（裂石）、二樓機關（`zip`）、石牆、巡邏／追擊怪、頭目與頭目寶箱，結構與前幾個洞窟一致。
- `mazeObjects` 的主題判斷要擴充成第四種（天空）；不能破壞 gc／xc／zc 既有行為，它們在 `mazes.ts` 的內容一格都不能變。
- 同一洞窟兩層共用 `group`；產生出的怪物 id 用 `mon1`…。

## 戰鬥

- 新敵人：雲朵怪（`cloudy`，一般）、星星精靈（`sprite`，回音怪）、流星獸（`comet`，回音怪）、星門守衛（`starguard`，小王，`shield: true`）、星空龍王（`skydragon`，最終頭目，`shield: true`）。
- 強度（暫定，需過 `tests/difficulty.test.ts`）：cloudy 36／6、sprite 38／6（echo）、comet 40／7（echo）、skydragon 52／8（頭目、護盾）。第六關小怪血量下限要高於第五關小怪上限 34、攻擊下限不低於 6；小王 starguard 46／7（高於小怪、低於最終頭目）；最終頭目 skydragon 52／8，血量要高於熔岩獸 42。`difficulty.test.ts` 的第六關一列把 `starguard` 也算進「頭目比同關小怪強」的檢查（可作為 `boss` 之前的中間項，不破壞既有規則）。
- 戰鬥規則（回音怪、頭目護盾）沿用既有實作，不改邏輯。
- `boss_s1`（星門守衛，小王）：`focus` 是 ㄗㄘ，`review` 是前面學過的符號；獎勵給 `whistle` 並設旗標 `sPractice`，戰後上 ㄙ 的第一次認識符號的課。
- `boss_s`（星空龍王，**畢業考**）：`focus` 與 `review` 設成全部 21 個聲母（沿用 `BattleDef` 的 focus／review 機制，不改出題邏輯），實際出現的仍是「已學過 ∩ 家長開放」的符號；打到這裡全部都學過了，所以是真正的全部聲母。家長設定只開放部分符號、沒有音檔或固定只看符號時，照現有規則降級（只考開放的、改看符號配對）。題目權重沿用現有的錯題加權。

## 風險

- 新圖樣數量最多，先以簡單可辨認為主。
- 小王與最終頭目都是護盾戰，機器人與家長設定都要走既有的降級規則；星塔入口 `showIf: 'boss_s1'` 的順序要用測試守住，避免孩子在沒有 ㄙ 的情況下進塔後卡關。
- 稱號免費化會動到星星婆婆的兌換資料與測試，要小心不破壞既有兌換。
- 氣球／雲朵小船跳過「靠水」檢查會動到 `hub.test.ts`，要確保其他碼頭的檢查不變。
- 起始村新增三個物件要選在可走空地，並用測試鎖住不動既有物件。
