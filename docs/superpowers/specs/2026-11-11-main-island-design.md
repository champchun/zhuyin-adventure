# 主島「鼓聲港」（階段 4a）

日期：2026-11-11　狀態：使用者已確認（住宿費 25 金幣）

承接 `2026-11-11-level-structure-design.md` 的「一關 = 主島加兩座怪物島」。這次只做**舌尖中音島這一關的主島**，並接上現有的舌尖中音島（暫時當作怪物島 A）。把兩座怪物島重做成多層大迷宮是之後的階段 4b。

## 範圍

- 新增主島「鼓聲港」（地圖 `dh`），有島民、旅館、商店、碼頭。
- 新增兩張室內地圖：旅館（`dh_inn`）、商店（`dh_shop`）。
- 村子下面第四扇圓門改成通往主島；現有的舌尖中音島（`d`）暫時當怪物島 A，出口改回主島。
- 另一座怪物島（B）的入口先封著，用告示牌說明「還在迷霧中」。
- **不做**：重做怪物島成多層大迷宮、怪物島 B 的內容。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 進入方式 | 起始村第四扇圓門 → 主島；主島有「回起始村的圓門」出口 |
| 碼頭 | 第一次到主島，起始村的碼頭才會出現（`dockOpen`）；之後可免費搭船在兩座主島之間來回 |
| 旅館 | 住一晚 **25 金幣**：夥伴 HP／魔力回滿並存檔；**金幣不夠就不能住**，老闆提醒「搭船回起始村，回家睡覺是免費的」 |
| 商店 | 沿用現有商店的畫面與貨品（小藥水、魔力果、大藥水） |
| 島民 | 三位，依進度（`dPractice`、`boss_d`）說不同的話；最後一句不設條件 |
| 被打倒 | 在怪物島輸了，送回主島（`respawn` 位置），夥伴 HP／魔力回滿，不扣錢 |
| 怪物島入口 | 主島西邊的出口通往現有舌尖中音島；另一座怪物島的入口是告示牌 |

## 主島地圖（`dh`，28×20）

- 沙灘小島，四周是海。東邊有一個海灣，碼頭在它旁邊。
- 北邊兩棟房子：左邊旅館（門 (6,3)），右邊商店（門 (21,3)）。
- 一條橫向的路（y=4）連到兩扇門，一條直向的路（x=14）通到南邊的出口。
- 南邊出口 `back`（(14,18)）回起始村的圓門前；西邊出口 `isle_a`（(2,10)）通往怪物島 A；東南的告示牌 `isle_b`（(24,16)）封著怪物島 B。
- 起點 (14,17)；被打倒後的位置 `respawn` (7,4)（旅館門前的路）。

## 旅館流程

1. 跟老闆說話 → 打招呼。
2. 金幣不夠（< 25）：說明不夠、提醒搭船回家免費，結束，**不扣錢**。
3. 金幣夠：問「住一晚要 25 金幣？」，選「住一晚」才扣錢、淡出、HP／魔力回滿、存檔、老闆道別；選「先不要」什麼都不發生。

## 資料與程式

- `MapObj.price?: number`；`ObjKind` 新增 `'innkeeper'`；`MapDef.hub.opensDock?: boolean`。
- `src/core/inn.ts`：純函式 `stayOutcome(coins, price)`。
- `src/core/travel.ts`：`markArrival` 在 `hub.opensDock` 時設 `dockOpen`。
- `src/data/maps.ts`：新增 `dh`、`dh_inn`、`dh_shop`；島 `d` 的出口改回主島。
- `src/data/levels.ts`：`LEVELS.d.mapId` 改成 `'dh'`；`STORY.innHello`、`STORY.innBye`。
- `src/scenes/World.ts`：旅館老闆的畫法與互動 `useInn`。

## 測試

- 單元測試：`stayOutcome`（夠、剛好、不夠、舊存檔沒有金幣）；`markArrival` 開放碼頭；`defeatSpot('dh')` 回主島；主島與室內地圖的資料完整性（門的目的地互相對得上、碼頭在落腳點旁、旅館價格 25、島民最後一句不設條件）。
- 端對端：進主島、旅館（沒錢不能住、有錢住一晚並回滿 HP 扣 25 金幣）、走到怪物島 A、回主島、回起始村。

## 風險

- 現有端對端與一般地圖測試假設第四扇圓門直接進島、島的出口回村子，要一併更新。
- 碼頭的圖背景是水，要放在水邊（主島的碼頭放在海灣旁，起始村的碼頭位置之前已標為外觀小問題）。

## 不在範圍

怪物島的多層迷宮重做、怪物島 B 的內容、主島的新道具或新商品、世界地圖的外觀。
