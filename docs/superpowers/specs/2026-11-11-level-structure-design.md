# 關卡結構重做：主島＋兩座怪物島迷宮

日期：2026-11-11　狀態：設計已與使用者逐段確認，待使用者審閱本文件

## 背景與目標

目前一關只有一座島（舌尖中音島），內容平面、重複。為了讓每一關更豐富、後面不疲乏，把一關改成：

- **一座主島**：島民、旅館、商店、碼頭。
- **兩座怪物島**：多層迷宮，怪物會移動，有鑰匙、機關、隱藏房間。

對象是幼兒園到小一的孩子，所以重點是「豐富但不迷路、沒有時間壓力、不會卡關」。

## 範圍

- 包含：新的關卡結構、世界地圖與碼頭、旅館、會動的怪物、迷宮元件、迷宮驗證。
- **不包含：第 0 關（起始村、村外小徑、風車草原）完全不動**，之後再決定怎麼搬進新模板。
- 不包含：新島的實際關卡內容（舌尖中音島要照新模板重做，另開計畫）、舌根音島以後的內容。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 一關結構 | 主島＋兩座怪物島 |
| 符號分配 | 以 ㄉㄊㄋㄌ 為例：島 A 教前兩個（ㄉㄊ）、島 B 教後兩個（ㄋㄌ）並複習前面的 |
| 頭目 | 島 A 最深處有中頭目；島 B 有中頭目，再往下是大頭目。打過島 A 的中頭目才開放島 B |
| 迷宮層數 | 島 A 2 層、島 B 3 層 |
| 迷宮大小 | 每層約 40×30 格（約 2×2 個畫面）；通道盡量寬 2 格；每層岔路 3～4 個 |
| 迷宮元件 | 岔路與死路、多層樓梯、鑰匙與機關門、隱藏房間與捷徑 |
| 怪物移動 | 同步回合制：玩家走一格，怪物才各走一格；玩家不動，怪物不動 |
| 一樓怪物 | 沿固定路線巡邏 |
| 二樓以上怪物 | 主角在約 5 格內就追，每回合朝主角走一格（走最短路，被擋就停，不穿牆） |
| 接觸 | 怪物走到主角旁、或主角走到怪物旁，就進入戰鬥 |
| 撤退 | 撤退回到迷宮後，該怪物暫停 3 步 |
| 旅館 | 收費，住一晚回滿 HP／魔力並存檔；**沒錢就不能住** |
| 沒錢怎麼辦 | 搭船回起始村，回家睡覺免費 |
| 世界地圖 | 每座主島與起始村都有碼頭，隨時免費搭船到任何去過的主島（含起始村） |
| 被打倒 | 送回「最近的主島」，免費睡一次，沒有懲罰 |
| 家長設定 | 新增「怪物會動」開關，預設開 |

## 一關的組成

```
主島（hub）
 ├─ 島民（依進度給提示和小故事）
 ├─ 旅館（收費、存檔）
 ├─ 商店（該關上架新貨）
 ├─ 碼頭（開世界地圖）
 ├─ 通往怪物島 A 的入口
 └─ 通往怪物島 B 的入口（打過島 A 中頭目才開）

怪物島 A：迷宮 2 層 → 中頭目
怪物島 B：迷宮 3 層 → 中頭目 → 大頭目
```

怪物島只能從主島進出；迷宮走到出口就回到主島。

## 世界地圖與回家

- 碼頭是一個物件，互動後開彈窗（做法同道具店），列出「已去過的主島」。
- 選一個就免費搭船過去，落在該島的碼頭旁。
- 「去過」用旗標記：進入主島時設 `visited:<mapId>`。
- 存檔新增一個欄位：最近一次到過的主島（`homeMap`）。每次進入主島時更新。被打倒時送回這裡。

## 旅館

- 旅館老闆是一個 NPC，物件上帶 `price`（金幣）。
- 互動後問「住一晚 N 金幣？」：
  - 金幣夠：扣錢、`healAll()`、`saveGame()`、播放睡覺過場。
  - 金幣不夠：老闆說明，並提醒「搭船回家睡覺是免費的」，不住、不扣錢。
- 起始村的家（床）維持免費。

## 會動的怪物

規則寫成獨立模組 `src/core/monsters.ts`（不依賴 Phaser，可單元測試）。

- **同步**：World 每完成玩家一步，就呼叫一次「怪物回合」。點地面自動走路時，每一步都算一回合。玩家不動就不呼叫。
- **巡邏（一樓）**：怪物有 `patrol` 路線（座標列表），來回或繞圈，每回合走一格。路線被擋（有怪或玩家）就原地等一回合。
- **追擊（二樓以上）**：玩家與怪物的最短路徑長度 ≤ 5 時，每回合沿最短路走一格；路徑不存在就停住；超過範圍就回到巡邏或原地。
- **碰撞規則**：怪物不穿牆、不重疊、不進樓梯格和寶箱格、不進入已有其他物件的格子。
- **接觸**：玩家一步之後、或怪物一步之後，只要相鄰（上下左右）就觸發戰鬥。同一回合有多隻怪相鄰，只開一場戰鬥，其他怪暫停。
- **撤退**：戰鬥結果是「撤退」時，該怪物 `stun = 3`，接下來 3 個回合不動、也不會觸發接觸。
- **重生**：離開島再回來，野生怪回到初始位置（沿用現有重生規則）；頭目、練習布偶不重生。
- **關閉**：家長設定「怪物會動」關掉時，怪物保持原地不動，其餘行為與現在一樣（點怪物才開戰）。
- **不能跑的時候**：對話、戰鬥、彈窗、轉場期間（`busy` 或 `ui.blocking`）不跑怪物回合。

## 迷宮元件

- **多層**：每一層是獨立地圖，id 例如 `d1a_1`、`d1a_2`。樓梯物件連到另一層的指定座標。旗標沿用 `m:<map>:<id>`、`c:<map>:<id>`，每層各自記錄。
- **岔路與死路**：死路盡頭放寶箱當獎勵；岔路口放告示牌，用簡單的圖或顏色提示方向。
- **鑰匙與機關門**：
  - 鑰匙是道具（`key_<島>_<編號>`），放在地圖某處，有的要打怪守著、有的要用招式才拿到。
  - 鎖門物件需要鑰匙才能通過，用掉一把。
  - 開關物件用本島招式啟動，設旗標，對應的機關門打開。
- **隱藏房間與捷徑**：沿用現有的裂石、迷霧等機關物件；捷徑是打通後連回入口的單向通道。

## 資料結構

- **文字圖**：迷宮用 ASCII 文字圖手寫（每層一個字串陣列），新增一個 `fromAscii()` 把字元轉成格子，物件另外列表。放在 `src/data/dungeons/`。
- **新物件種類**（`ObjKind`）：`stairs`、`lockdoor`、`switch`、`dock`、`innkeeper`。
- **怪物物件新欄位**：`patrol?: {x, y}[]`、`ai?: 'patrol' | 'chase'`。
- **一關設定**：`LevelDef` 增加 `home`（主島地圖）、`dungeons`（兩座怪物島）、符號分配、大頭目。
- **存檔**：不改格式。新增 `homeMap`（有預設值，舊存檔自動補）。鑰匙、開關、去過哪些島都用旗標。
- **設定**：新增 `monstersMove: boolean`，預設 `true`。

## 程式拆分

| 單元 | 責任 | 依賴 |
|---|---|---|
| `core/monsters.ts` | 巡邏、追擊、暫停、碰撞、接觸判斷（純函式） | 地圖資料（可走格） |
| `data/dungeons/*` | 各層文字圖與物件 | `fromAscii`、物件型別 |
| World 場景 | 每步呼叫怪物回合、依結果移動圖片、觸發戰鬥 | `core/monsters.ts` |
| 碼頭彈窗 | 列出已去過的主島、搭船 | 旗標、`travel()` |
| 旅館流程 | 收費、回滿、存檔 | 存檔函式、金幣 |

World 目前把物件座標放在 `def.x / def.y`（固定）；要改成物件上有可變的目前位置，通行判定與尋路都改用目前位置。

## 測試

- **單元測試**：
  - 怪物規則：巡邏路線、追擊最短路、超出範圍、被擋就停、暫停 3 步、不重疊、同回合多隻怪只開一場戰鬥。
  - **迷宮驗證**：模擬「拿鑰匙、用招式、開開關」的順序，確認每個寶箱、樓梯、頭目都走得到，且不會有卡死的迷宮。
  - 旅館：夠錢能住、不夠錢不能住且不扣錢。
  - 被打倒送回 `homeMap`，且 HP／魔力回滿。
  - 碼頭：只列出去過的主島。
- **端對端測試**：機器人用座標點擊走路，怪物一動就會亂掉，所以測試時把「怪物會動」關掉，只驗證流程；怪物移動由單元測試負責。

## 風險與注意事項

- 所有對話與彈窗都要成對增減 `ui.blocking`（專案曾因 `say([])` 例外造成地圖鎖死）；怪物回合與接觸戰鬥都要遵守。
- 迷宮要避免卡死：鑰匙不能放在需要同一把鑰匙才能進去的區域；機關招式必須在進入該島前或該島內較早的位置就學到。
- 迷宮大小以 40×30 為上限；通道寬、岔路少、有路標，避免幼兒迷路。
- 沒錢不能住旅館，但回家與搭船免費，所以不會因為金幣不夠而卡關。

## 實作分階段（各自可玩、可驗證）

1. **世界地圖與碼頭**：`homeMap`、`visited` 旗標、碼頭彈窗、被打倒送回主島。
2. **會動的怪物**：`core/monsters.ts`、World 整合、家長設定開關。
3. **迷宮元件**：樓梯、鎖門、開關、`fromAscii`、迷宮驗證測試。
4. **主島模板**：島民、旅館、商店，並用它重做舌尖中音島（主島＋兩座怪物島）。

每個階段各自寫實作計畫、各自測試。
