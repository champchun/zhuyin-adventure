# 第二階段第四關（第十關，最終關）：齒輪鐘塔城（ㄢ ㄣ ㄤ ㄥ ㄦ）

日期：2026-11-18　狀態：使用者已確認方向（齒輪鐘塔城、熱氣纜車、發條島、時光守護者、最終關收尾與「注音大師」稱號），其餘細節為我的建議，待使用者審閱本文件
上位文件：`docs/superpowers/specs/2026-11-17-stage2-overview-design.md`；前一關：`2026-11-18-castle-level-design.md`（第九關，本關大部分做法照抄，只寫差異）。

## 背景與目標

- 第九關教了 ㄞㄟㄠㄡ。本關教最後 5 個符號 **ㄢ ㄣ ㄤ ㄥ ㄦ**，只教「認識」：看符號、聽音、描筆順，不教拼音。
- 結構沿用第九關：主島、怪物島、一個兩層迷宮、一個護盾頭目、回家魔法陣；多了「最終關收尾」（見下）。
- 入口是世界地圖大廳的第四扇門（`gate10`）。**打倒第九關的幽靈伯爵（旗標 `boss_c`）後才開放**，沒打倒時維持擋路並說明原因。

## 學習流程與招式

| 符號 | 怎麼學到 | 招式（id／名稱／魔法名） | 機關 |
|---|---|---|---|
| ㄢ | 進發條島後先打發條人偶的練習戰（教學戰）。`LEARN_STEPS`：`['ㄢ','ㄣ']`，旗標 `tEntered`（已存在） | `chime` 噹噹響（鐘聲魔法）：「ㄢ」嘴巴張開、舌尖頂上牙，像說「安」 | 停擺的大齒輪，轉起來後旁邊冒出寶箱 |
| ㄣ | 同上 | `crank` 轉發條（發條魔法）：「ㄣ」嘴巴微開、舌尖頂上牙，像說「恩」 | 沒發條的八音盒，上緊後旁邊冒出寶箱；鐘塔二樓的**開關（大發條）**也用它 |
| ㄤ | 練習戰完成後開始教（`LEARN_STEPS`：`['ㄤ','ㄥ','ㄦ']`，旗標 `tPractice`，已存在）；打倒頭目後學會招式 | `bark` 昂昂叫（昂叫魔法）：「ㄤ」嘴巴張大、聲音往鼻腔走，像說「昂」 | 壞掉的齒輪橋，轉起來後架成橋，通過水溝到對岸 |
| ㄥ | 同上 | `rumble` 轟轟響（轟鳴魔法）：「ㄥ」嘴巴微開、聲音往鼻腔走，像說「鞥」 | 緊閉的鐘樓大門，震開後隱藏的寶箱出現 |
| ㄦ | 同上 | `curl` 捲舌（捲舌魔法）：「ㄦ」舌頭往後捲，像說「兒」 | 轉不動的大鑰匙孔，轉開後隱藏的寶箱出現 |

- 威力：ㄢ 14、ㄣ 14、ㄤ 15、ㄥ 15、ㄦ 16（比第九關再高一級）。
- 招式資料比照現有招式；能力 id 與招式 id 相同；`fx` 同 id。每個招式有說明文字（怎麼擺嘴型）。id 與魔法名不得和既有招式重複（開工前 grep 確認）。
- **能力取得**：練習戰獎勵 `abilities: ['chime','crank']`、旗標 `tPractice`；頭目 `boss_t` 獎勵 `abilities: ['bark','rumble','curl']`、旗標 `boss_t`。
- **死結守門**：鐘塔二樓開關用 `crank`（練習戰就學到）；`bark`／`rumble`／`curl` 的機關只放在頭目之後；通往 `boss_t` 之路所需能力全部在頭目之前取得，以測試守住；`cave` 要練習戰之後才出現（`showIf: 'tPractice'`）。
- 齒輪與八音盒各有一個寶箱，放在機關旁邊的空地、啟動後才出現（`showIf`），不得被圍成口袋。

## 場景與地圖

地圖字元走 skin：新增 `SKINS.clock`（擋路字元表 `'#RO~hHiIkKDW'`，與前幾關相同），本關新地圖（`th`、`t`、`tc1`、`tc2`）設 `skin: 'clock'`；室內 `th_inn`／`th_shop` 沿用預設室內地形、不設 skin。

### 大廳

- `gate10`（目前是 `barrier`，座標 (15,2)）拆成同格兩個物件：`gate10`（`barrier`，`hideIf: 'boss_c'`，`lockText` 說明「要先打倒第九關的幽靈伯爵，這扇門才會開」）與 `gate10_open`（`stairs`，貼圖 `clock_gate`，`showIf: 'boss_c'`，通往齒輪鎮抵達格，標籤「時鐘塔」）。

### 主島「齒輪鎮」（`th`，室內 `th_inn`、`th_shop`）

- 一座由齒輪與發條組成的小鎮：銅色屋頂、齒輪裝飾、噴著蒸氣的水池。`hub`、旅館（25 金幣）、商店、島民、星星婆婆、金幣爺爺（`GIVER_HUBS` 加 `'th'`）。
- 鐘塔大門 `stairs`（貼圖 `clock_gate`）回大廳；熱氣纜車站（`dock`，`vehicle: 'cablecar'`，貼圖 `cablecar`）通往發條島，雙向。沒有海面碼頭。
- 旅館老闆與店員台詞要有齒輪鎮特色，各有自己的招呼與道別，招呼第一句提到「齒輪鎮」，店員招呼有提到藥水或魔力果。
- 被打倒送回齒輪鎮（旗標 `visited:th`）。

### 怪物島「發條島」（`t`）

- 進島：發條人偶（練習戰，教 ㄢㄣ）、三種小怪、機關（齒輪 ㄢ、八音盒 ㄣ 各一個寶箱；齒輪橋 ㄤ、鐘樓大門 ㄥ、鑰匙孔 ㄦ 要頭目之後）、一條水溝（缺口一格，齒輪橋）、告示牌、纜車站（回齒輪鎮）、通往鐘塔的入口 `cave`（`showIf: 'tPractice'`）。
- 水溝是橫向（y=10，缺口 (14,10)），抵達點在北側，`cave` 與練習戰前能走到的物件都在北側；齒輪橋架在缺口上，對岸（南側）有兩個寶箱。齒輪橋與其他滿格圖樣一樣要畫滿整格。
- 齒輪、八音盒、鐘樓大門、鑰匙孔不是 `vanish`／`passable`（齒輪橋才是 `passable`）：啟動後換成 `sprite2` 並留在原地，寶箱放旁邊、啟動後才出現。

### 鐘塔（`tc1`、`tc2`，產生器）

- 兩層，固定種子 **107、109**（避開既有 11、23、37、41、53、59、67、71、79、83、89、97、101、103），31×22；`tools/gen-dungeon.mjs` 新增 `tc1`／`tc2`，輸出 `src/data/mazes.ts`；既有十四個迷宮內容一格都不能變。
- 結構與前面一致（樓梯、鑰匙、鎖門、隱藏房間、二樓機關、擋路牆、巡邏／追擊怪、頭目與頭目寶箱、回家魔法陣）。`mazeObjects` 主題判斷加 `t` 開頭 → `'clock'`；二樓開關是**大發條**（`gimmick`，貼圖 `winder_off`／`winder_on`，`ability: 'crank'`，`fx: 'crank'`，打開後 `barrier1` 消失）。迷宮地形由 `clockRows` 把原始格子轉成 `clock` skin 的字元。
- 兩層共用 `group: 'tc'`；怪物 id 用 `mon1`…；回家魔法陣 `CIRCLE_HOME.tc` → 齒輪鎮旅館門外一格，`showIf: 'boss_t'`。
