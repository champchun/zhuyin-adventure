# 星星婆婆：用星星碎片換獎勵、解鎖隱藏房間

日期：2026-11-12　狀態：使用者已確認方向（星星花掉換獎勵、隱藏房間看累計星星、造型用小飾品、做成一個酷炫的星星婆婆角色，不是一間屋子），細節為我的建議，待使用者審閱本文件

## 背景與目標

- 星星碎片現在只在開寶箱時得到（1 或 2 顆，全遊戲約 50～60 顆），只顯示在家長頁，沒有任何用途。
- 讓星星有用：集滿可以換獎勵（稱號、夥伴小飾品、小禮物），累計夠多還能打開一間隱藏小房間。

## 已確認的決策

| 項目 | 決定 |
|---|---|
| 換獎勵 | 花掉星星（有「可用星星」＝累計 − 已花掉） |
| 隱藏房間 | 看**累計**星星，不看可用星星，換獎勵不會讓孩子被擋在門外 |
| 夥伴造型 | 小飾品（蝴蝶結、小皇冠）疊在夥伴頭上，不為每隻夥伴重畫圖 |
| 星星婆婆 | 一個酷炫的角色（會發光的婆婆），不蓋星星屋 |

## 星星婆婆

- **在哪裡**：三座主島（鼓聲港 `dh`、蛙鳴灣 `gh`、雪花鎮 `xh`）的碼頭附近各站一位，**同一個人**，台詞一樣。起始村（第 0 關）不動。孩子到第二關主島才第一次看到她（不放在起始村，因為第 0 關內容不能動）。
- **酷炫**：
  - 身上有光暈（柔和閃爍的光圈）、周圍有幾顆旋轉的小星星、披斗篷、拿星星杖（程式畫的像素圖，兩格動畫）。
  - 第一次跟她說話有一小段登場台詞：「喔呵呵～小探險家，你身上有星星的味道！」。
- **功能**（對話後開「星星換獎勵」彈窗）：顯示「可用星星 N 顆（累計 M 顆）」，列出獎勵清單，點選兌換；兌換後扣可用星星，已換過的獎勵標「已擁有」。
- 沒有任何處罰：星星不夠就把獎勵顯示成灰色並說「再多撿幾顆星星就能換囉～」。

## 獎勵清單

| 星星 | 獎勵 | 效果 |
|---|---|---|
| 5 | 稱號「小探險家」 | 顯示在標題畫面存檔資訊與夥伴頁 |
| 10 | 飾品：蝴蝶結 | 夥伴頭上戴蝴蝶結（世界跟隨者與戰鬥畫面都顯示） |
| 20 | 稱號「注音小達人」 | 同上 |
| 30 | 飾品：小皇冠 | 同上 |
| 40 | 小禮物 | 大藥水 ×2（可重複換，每次 40 星） |

- 稱號與飾品只換一次；一次只能戴一個飾品（兌換後自動戴上，可在婆婆那裡換成別的或脫下）。
- 稱號只做展示，不影響遊戲。

## 隱藏房間「星光小屋」

- 位置：雪花鎮東北角一道「星光門」（`stairs`／`door` 類出口物件）。累計星星 ≥ 25 才打得開；不夠時門旁對話說「星光門還在睡覺，要 25 顆星星才會醒來（現在 M 顆）」。
- 內容：室內一間小屋（`xh_star`），有一個大寶箱（大藥水 ×2、魔力果 ×2）和一座星星雕像，雕像互動說一句鼓勵的話；之後要加內容再說。
- 出口回雪花鎮門口。

## 資料與程式

- `SaveData`：新增 `starsSpent: number`（預設 0）、`titles: string[]`（已擁有稱號）、`accessories: string[]`（已擁有飾品）、`equipped?: string`（目前戴的飾品，`bow`／`crown`）、`title?: string`（目前顯示的稱號）。舊存檔讀入時補預設值，不改版本號。
- `src/data/rewards.ts`：獎勵清單資料（id、type: title|accessory|gift、cost、name、icon）。
- `src/core/stars.ts`（純邏輯，Vitest 測）：`availableStars(save)`、`canRedeem(save, reward)`、`redeem(save, reward)`（回傳新狀態或原因）、`starDoorOpen(save)`（累計 ≥ 25）。
- `MapObj` 新增 `kind: 'granny'`；World 的互動新增 `useGranny`（彈窗 + 登場台詞，`ui.blocking` 成對）。
- 美術（`src/gfx`）：星星婆婆（含光暈與旋轉星星動畫）、蝴蝶結、小皇冠（疊在夥伴頭上的圖，依夥伴大小定位）、星光門、星光小屋室內地形（沿用既有字元，必要時新增）。
- 重要：不動第 0 關（起始村）、試煉洞窟與已有的地圖物件座標，只在三座主島加物件；既有 `tests/layout.test.ts` 的凍結物件若涉及這些島，要同步更新並說明。

## 測試

- 單元測試：兌換邏輯（星星不足、重複稱號、飾品互斥與脫下、禮物可重複、扣可用星星不動累計）、星光門條件（用累計，花掉不影響）、舊存檔預設值、獎勵資料完整性。
- 地圖測試：三座主島都有婆婆且站在可走格旁；`xh` 有星光門，目的地 `xh_star` 存在、抵達格可走且回程出口對得上；`hub.test.ts` 通用規則不變。
- 端對端：新增一小段（掛在 `lv4` 尾端）：把星星設成足夠數量，跟婆婆換飾品，打開星光門進小屋開寶箱；不在本機跑。
- 手動確認：婆婆的外觀酷不酷、飾品在夥伴頭上的位置，交給使用者看過後調整。

## 風險

- 飾品要疊在不同夥伴的頭上，位置得逐隻對（現在有三隻初始夥伴加幾隻同伴）；先支援全部現有夥伴，位置用每隻夥伴一個偏移值，使用者看過後再調。
- 星星來源只有寶箱，累計 25 顆要在第三關以前很難拿到；25 的門檻放在第四關的雪花鎮，這時孩子大約已有 30 顆以上（以現有寶箱數估，需要實測）。如果門檻不合適只要改一個常數。
- 彈窗的星星換獎勵要保證 `ui.blocking` 成對（AGENTS.md 的規則）。

## 不在範圍

怪物擊敗給星星、更多飾品、飾品影響戰鬥數值、第 0 關起始村的任何改動、星星商店販售金幣道具。
