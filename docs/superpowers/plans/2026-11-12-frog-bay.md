> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 蛙鳴灣（`gh`）現在只是鼓聲港換名字。讓它變成「荷葉池塘水鄉」：中間一大片池塘，用木板橋與荷葉墊腳石連起來；池塘中的荷葉島上有一尊「青蛙聽音石」——一個只有這座島才有的小玩法，孩子聽注音聲音、點對的石頭，答對 3 題送獎勵。

**使用者已確認（2026-11-12）：** 特色選「荷葉池塘水鄉」，並要加「簡單的」只有這座島才有的玩法（青蛙聽音石：聽一個注音聲音，點對的石頭，答對就送金幣或魔力果，可重複玩，順便練聽音）。

**Tech Stack:** TypeScript、Vite、Phaser 3.80、Vitest。

```ts
// 蛙鳴灣的青蛙聽音石：聽一個注音的聲音，從 3 個石頭裡點對的那個（純函式）。
export const FROG_ROUNDS = 3;
export const FROG_REWARD = { coins: 10, item: 'berry' as const, count: 1 };

export interface FrogRound {
  /** 播放聲音的符號（答案） */
  target: string;
  /** 三個選項（已打亂，含答案） */
  options: string[];
}

function shuffle<T>(a: T[], rng: () => number): T[] {
  const r = [...a];
  for (let i = r.length - 1; i > 0; i--) {
    const j = Math.floor(rng() * (i + 1));
    [r[i], r[j]] = [r[j], r[i]];
  }
  return r;
}

/**
 * 出一題。pool＝已經學過的符號，不到 3 個就不出題（回傳 null）。
 * prev＝上一題的答案：pool 夠大時，這一題的答案不會和它一樣。
 */
export function makeFrogRound(pool: string[], prev?: string, rng: () => number = Math.random): FrogRound | null {
  const symbols = [...new Set(pool)];
  if (symbols.length < 3) return null;
  const candidates = symbols.length > 3 && prev ? symbols.filter((s) => s !== prev) : symbols;
  const target = candidates[Math.floor(rng() * candidates.length)];
  const others = shuffle(symbols.filter((s) => s !== target), rng).slice(0, 2);
  return { target, options: shuffle([target, ...others], rng) };
}
```

```ts
  /** 青蛙聽音石：聽一個注音的聲音，點對的石頭；答對 3 次有獎勵（每次進入蛙鳴灣只能領一次）。答錯沒有懲罰。 */
  private async useFrogStone(d: MapObj) {
    const who = d.label ?? '青蛙聽音石';
    const talk = (lines: string[]) => say(lines.map((text) => ({ who, text })));
    if (this.frogPaid) { await talk(STORY.frogAgain); return; }
    const pool = activeSymbols();
    if (pool.length < 3) { await talk(STORY.frogNeed); return; }
    if (!audio.audioReadyFor(pool)) { await talk(STORY.frogNoAudio); return; } // 沒有音檔不用 TTS 冒充，青蛙睡著了
    await talk(STORY.frogHello);
    let prev: string | undefined;
    for (let n = 0; n < FROG_ROUNDS; n++) {
      const round = makeFrogRound(pool, prev);
      if (!round) return;
      prev = round.target;
      for (;;) {
        audio.playSymbol(round.target);
        const labels = [...round.options, '🔊 再聽一次', '先不要'];
        const i = await choose(`第 ${n + 1} 題（共 ${FROG_ROUNDS} 題）`, '聽一聽，點對的石頭！', labels);
        if (i === round.options.length + 1) return; // 先不要
        if (i === round.options.length) continue; // 再聽一次
        if (round.options[i] === round.target) { toast(STORY.frogRight); break; }
        toast(STORY.frogWrong);
      }
    }
    this.frogPaid = true;
    G.save.coins = (G.save.coins ?? 0) + FROG_REWARD.coins;
    addItem(FROG_REWARD.item, FROG_REWARD.count);
    saveGame();
    audio.sfx('levelup');
    await talk(STORY.frogDone);
  }
```
先 Read 確認：`toast` 的簽名（接受一個字串嗎？）、`audio.audioReadyFor`／`audio.playSymbol` 存在、`addItem` 的簽名是 `(id, n)`、`audio.sfx` 的名稱 `'levelup'` 有效（`useItem` 戰鬥裡用過）；`STORY` 值型別有調整就照 Step 1 的備註。`activeSymbols` 在 `save.ts` 匯出，若 World 已經 import 它的地方就直接加進去。
