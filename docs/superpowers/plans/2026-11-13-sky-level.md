# 第六關（最終關：舌尖前音 ㄗㄘㄙ、天空島）實作計畫

> **For agentic workers:** 使用 superpowers:subagent-driven-development 逐個 Task 執行。設計見 `docs/superpowers/specs/2026-11-13-sky-level-design.md`（必讀）。

**Goal:** 做出第六關：起始村的熱氣球（對它施放 ㄖ 烤熱）→ 主島雲上小鎮 `sh` →（雲朵小船）怪物島星空島 `s`（小王星門守衛）→ 星塔 `sc1`/`sc2` → 最終頭目星空龍王（畢業考：全部 21 個聲母）→ 結尾劇情與稱號「注音大英雄」。

**Architecture:** 完全比照第五關（翹舌音）的實作方式。**先看第五關怎麼做的**：`git log --oneline` 找 `retroflex`／火山沙漠／綠洲鎮相關 commit，並讀 `src/data/{monsters,levels,maps,symbols,strokes}.ts`、`src/gfx/desertArt.ts`、`tools/gen-dungeon.mjs`、`tests/retroflex.test.ts`、`tests/hub.test.ts`、`tests/difficulty.test.ts`、`tests/giver.test.ts`、`tests/granny.test.ts`、`tests/settings-upgrade.test.ts`、`tests/e2e/play.mjs` 的 lv5 段落，以及 `docs/superpowers/plans/2026-11-13-retroflex-level.md`（舊計畫，對應關係相同）。對應：web/gulp/roar/sun → zip/spike/whistle；scorpion/cactusman/mummy/lavabeast → cloudy/sprite/comet（＋小王 starguard、最終頭目 skydragon）；zh/z/zc1/zc2 → sh/s/sc1/sc2；`boss_z` → `boss_s1`（小王）、`boss_s`（最終頭目）；旗標 zEntered/zPractice → sEntered/sPractice。**差別**：入口是起始村的熱氣球（機關＋交通工具，不是小路）；主島到怪物島是「雲朵小船」（交通工具，不靠水）；有**小王**（星空島上、星塔入口前，打倒後才學 ㄙ 並出現 `cave`）；最終頭目是畢業考；有結尾劇情與免費稱號。
