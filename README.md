# 注音夥伴：迷霧島冒險

給剛開始學注音的孩子玩的像素風 RPG：探索地圖 → 遇到怪獸 → 用注音指揮戰鬥 → 完成關卡 → 獲得夥伴與能力。
TypeScript + Vite + Phaser 3；介面（對話、按鈕、家長設定）用 DOM，美術全部由程式繪製（原創，無外部素材）。

## 執行

```bash
npm install
npm run dev        # 開發：http://localhost:5173（區網用 iPad 開同一個 IP 即可）
npm run build      # 型別檢查 + 打包到 dist/
npm test           # 單元測試（地圖連通性、出題與提示規則、學習統計）
node tests/e2e/play.mjs   # 端對端：開啟 dev server 後，用真實點擊從頭玩到尾（需系統有 Edge 或 Chrome）
SECTION=lv4 node tests/e2e/play.mjs   # 只測某一段：lv0 | lv2 | lv3 | lv4 | lv5 | all（預設）；前面的進度直接寫進存檔，比較快
```

## 操作
- iPad：點地面移動、點物件互動（寶箱、裂石、怪獸、圓門…）；怪獸在地圖上看得見，不會隨機遇敵。
- 電腦：方向鍵／WASD 也可移動；走向物件即互動。
- 右上角：🔊 重聽、🐾 夥伴（切換出戰）、⚙ 家長設定（需回答簡單算式）、🏠 回標題。

## 學習設計
- 題型：**看符號找一樣**（tier 1）、**聽聲音選符號**（tier 2）、**混合複習**（tier 3）。進度與難度分開：關卡只決定預設題型，家長可強制指定。
- 選項只來自家長開放的注音；位置隨機；無倒數。練習戰答錯不處罰；一般戰鬥與頭目答錯會「攻擊失敗、換對方攻擊」。
  - 答錯 2 次：拿掉一個錯誤選項（或直接亮出答案）；3 次：亮出正確符號。
  - 「提示」依序：文字／語音提示 → 拿掉一個選項 → 亮出答案。
- 統計（每個符號）：**獨立答對**（第一次就對且沒用提示）、**協助後完成**（不算獨立答對）、答錯、提示。容易答錯的符號會多出現，但不連續出同一題。
- 敵方在我方出招（或答錯、用道具）後反擊；戰敗不損失任何東西，回到最近的主島（旅館門前）恢復。
- 魔法攻擊（聽聲音）威力比普通攻擊（看符號）大、耗 1 點魔力；第 2 關起有只怕魔法的「回音怪」與有護盾的頭目，讓孩子練到聽音。

## 語音與音檔（重要）
- 劇情／提示：瀏覽器 `speechSynthesis`，優先 zh-TW，處理 `voiceschanged`；按「開始」時於使用者手勢內暖機（iOS Safari 要求）。找不到中文語音時保留文字、不卡關。
- **注音單音**：`public/audio/zhuyin/` 內的 37 個 mp3 是 Azure 語音合成產生的，**不是真人標準音**，需親耳確認；可用真人錄音同檔名覆蓋。音檔不齊（遊戲用到的 7 個缺任何一個）時，「聽音選符號」會自動降級成「看符號配對」，並在畫面與家長設定中明示。
  - 換音檔：放進 `public/audio/zhuyin/`，檔名對照見 `src/data/audioMap.ts`。
  - 家長設定內有「實驗：用 TTS 念單一符號」，發音未經驗證，預設關閉。
- 背景音樂與音效以 WebAudio 即時合成（原創簡單旋律），可關閉。

## 預先產生自然語音（Azure AI Speech）
瀏覽器內建語音（iPad 的「美佳」）偏機械，網頁也拿不到加強版語音。解法是預先用 Azure 產生 mp3，放進專案；遊戲有預錄檔就播檔，沒有就退回語音合成。

```bash
# 1. 在 Azure 建立 Speech 資源（建議付費層 S0），取得金鑰與區域
# 2. 金鑰只放環境變數，不要寫進檔案或 commit（PowerShell 範例）
$env:AZURE_SPEECH_KEY = "你的金鑰"; $env:AZURE_SPEECH_REGION = "eastasia"
npm run gen:voice -- --dry            # 只列出句子與字元數（不連線）
npm run gen:voice -- --only 你好      # 先產生含「你好」的句子，試聽語音是否滿意
npm run gen:voice                     # 產生全部（約 80 句、1,100 字元），輸出到 public/audio/voice/
npm run gen:voice -- --zhuyin-only    # 只產生 7 個注音的「呼讀音」到 public/audio/zhuyin/（不動劇情語音）
npm run gen:voice -- --zhuyin         # 劇情語音之外，另外產生 7 個注音
```
- 換語音：`AZURE_SPEECH_VOICE`（預設 `zh-TW-HsiaoChenNeural`）、語速 `AZURE_SPEECH_RATE`（預設 `-10%`）。
- 改了劇情文字後重跑即可，只會產生有變動的句子。含動態數字的句子（寶箱星星數、升級等級）無法預錄，仍用語音合成。
- 注音呼讀音是語音合成，**不是真人標準音**，產生後請親耳確認。ㄅㄆㄇㄈ 若教材採「ㄜ」呼讀，標準國語沒有對應字；預設直接把符號「ㄅ」丟給 Azure 念；可用 `AZURE_ZHUYIN_MODE=char`（念呼讀用字）或 `ipa`（音標，實測 Azure 台灣語音會回 400）切換，效果都需試聽驗證。
- 輸出的音檔會一併提交到 git；公開儲存庫等於公開散布，請先確認 Azure 條款（建議使用付費層）。

## iPad Safari 實機驗證清單（尚未在實機驗證）
開發環境沒有 iPad，以下需在實機確認（用區網 IP 開 `npm run dev`，或部署 dist/ 到 https）：
1. 點「新的冒險」後第一句劇情是否有聲音；無聲時看家長設定的語音狀態文字。
2. 靜音開關（側邊）關閉時音效／音樂是否播放；Safari 需先有一次點擊才能出聲。
3. 橫向與直向切換後畫面是否不被裁切、按鈕是否好點。
4. 長時間遊玩後語音是否堆疊／中斷；背景音樂在語音時是否降低。
5. 加入主畫面（PWA 全螢幕）時的邊緣安全區。
