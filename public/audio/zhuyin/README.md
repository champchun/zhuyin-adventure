# 注音單音檔放置處

把「可靠、授權可用」的注音單音檔放在這個資料夾，檔名需與 `src/data/audioMap.ts` 一致：

| 符號 | 檔名 |
|---|---|
| ㄅ | b.mp3 |
| ㄆ | p.mp3 |
| ㄇ | m.mp3 |
| ㄈ | f.mp3 |
| ㄉ | d.mp3 |
| ㄊ | t.mp3 |
| ㄋ | n.mp3 |

目前**沒有**附任何音檔。遊戲啟動時會偵測這些檔案；缺檔時自動進入「看符號配對」模式，
不會用未驗證的 TTS 假裝是標準發音。換副檔名（例如 .m4a / .ogg）只需改 audioMap.ts。
iPad Safari 對 .mp3 / .m4a 支援最穩。
